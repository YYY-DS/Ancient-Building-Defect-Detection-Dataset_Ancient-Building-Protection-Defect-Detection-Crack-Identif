## 数据集概述

本数据集专注于**古建筑结构表观缺陷的视觉检测与分类**，服务于古建筑保护、文物修缮及建筑遗产监测。数据涵盖六类典型古建缺陷，适配无人机巡检、建筑遗产普查及自动化病害识别等应用。

## 知识普及：古建筑缺陷视觉检测的技术要点

*   **缺陷形态多样**：从细长的裂缝到区域性的剥落，缺陷在形态、尺度上差异显著，需模型具备多类别特征提取能力。
*   **材质与纹理干扰**：古建筑表面材质（木材、砖瓦、彩绘）纹理复杂，可能与缺陷混淆，模型需依赖纹理与颜色特征进行区分。
*   **植被遮挡**：植物生长在建筑表面，可能遮挡其他缺陷特征，需采用多尺度特征融合策略。
*   **光照与视角影响**：古建筑多为户外拍摄，光照变化大，且拍摄角度多样，建议训练时加入亮度、对比度增强与视角变换。
*   **小目标检测**：裂缝、瓦片损坏等目标可能占比较小，需采用高分辨率输入或多尺度特征融合策略。
*   **应用闭环**：检测结果可导入文物保护GIS系统，结合历史影像进行损毁趋势分析，辅助修缮规划与保护决策。

## 快速开始（代码示例）

配置文件 `data.yaml` 示例：
```yaml
train: ./dataset/images/train
val: ./dataset/images/val
nc: 6
names: ['crack', 'plant', 'contamination', 'peeling', 'soil', 'tile_damage']
```

启动 YOLOv8 训练：
```python
from ultralytics import YOLO

model = YOLO('yolov8m.pt')
model.train(
    data='data.yaml',
    epochs=100,
    imgsz=640,
    batch=16,
    device=0
)
```
